01Concept · 8 min

Context Engineering

Output quality is bounded by context quality, not prompt cleverness. Context Engineering is the discipline of deliberately curating what an AI system can see — data, tools, constraints, history — before it's asked to do anything.

  • Real-world anchor: Claude Code reads a CLAUDE.md file at the start of every session — the same idea, applied to a whole engineering org, so every session starts grounded instead of guessing.
  • A vague ask plus no context doesn't produce a cautious agent — it produces a confident, wrong one.
  • Today's artifact, context.md, is that file: the thing you'd want any agent — or any new teammate — to read before touching this problem.

02Concept · 8 min

Agent-Ready Problem Framing + HITL Gates

Before any agent writes code or takes action, translate the business ask into five explicit fields — the agent equivalent of an API contract.

  • Objective — one sentence, no ambiguity.
  • Allowed Tools & Data — exactly what it can read, never assumed.
  • Guardrails — what it must never do unsupervised. This is where irreversible actions get named explicitly.
  • Definition of Done — what "finished" looks like, so it doesn't keep going past the useful point.
  • Escalation Path — what happens when it's uncertain, instead of guessing confidently.

S1's Demo 2 (prior-auth triage) was already a miniature version of this: flag the procedural cases, escalate the clinical judgment calls to a human. Today you write that spec explicitly, on purpose, before any code exists.

03Concept · 8 min

Cost of Problem vs. Cost of Existence

Cost of Problem (COP) — what the problem costs every month it stays unsolved. Cost of Existence (COE) — what it costs to build and run the solution, including compute, maintenance, and governance overhead, not just the initial build.

  • Real-world anchor: Cost of Delay (Reinertsen) — treating urgency as a number instead of a feeling.
  • An elegant agent that costs more to run and govern than the problem it solves is a bad build, no matter how clean the code is.
  • This is the artifact you bring to a sponsor — not "AI will help," but a number with a payback period.

Articulate Cost of Problem vs. Cost of Existence

Switching to the Healthcare case from S1. All dollar figures below are illustrative training assumptions — swap in real numbers on the job.

Lab: Payer Ops

Uses prior_auth_requests_synthetic.csv from S1
Framework used: Cost of Delay · Total Cost of Ownership
  1. Scale the verified sample to monthly volume4 min
    YOU TYPE"We're scaling this PA triage pattern to a network processing about 1,200 requests/month, using the same procedural/clinical split we found in the sample data. Use code execution to project monthly volumes for approved, procedural-denial, and clinical-denial buckets."
    Verified: ≈ 274 approved · 549 procedural · 377 clinical (scaled from the 70-request sample's 59.3% / 40.7% denial split).
  2. Calculate Cost of Problem5 min
    YOU TYPE"Assume 1.5 hours of staff rework per procedural denial at a fully-loaded rate of $45/hour. Calculate the monthly Cost of Problem for the procedural-denial backlog alone."
    Verified: ≈ $37,058/month.
  3. Calculate Cost of Existence6 min
    YOU TYPE"Now calculate Cost of Existence: a one-time build of 120 engineering hours at $85/hour, plus ongoing monthly cost of about $0.02 per request analyzed and 8 hours/month of monitoring and governance at $85/hour."
    Verified: one-time build ≈ $10,200 · steady-state monthly ≈ $704.
  4. Net benefit and payback5 min
    YOU TYPE"If the agent cuts rework time on procedural cases by 40% — from 1.5 hours to 0.9 hours — what's the net monthly benefit after Cost of Existence, and what's the payback period on the build cost?"
    Verified: net monthly benefit ≈ $14,119 · payback ≈ 0.72 months (about 3 weeks).
  5. Debrief2 min
    DISCUSSA 3-week payback is a genuinely strong business case — and it only exists because Cost of Existence (governance, monitoring, ongoing run cost) was counted honestly instead of ignored.
Checkpoint A short cost model — COP, COE, net benefit, payback period — you could present to a sponsor in under 2 minutes. Reference script: cost_model.py.
